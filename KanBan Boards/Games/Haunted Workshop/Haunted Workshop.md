A haunted empty sky scrapper, each floor has several apartments and each apartment has a valuable very expensive crystal.
And each floor has a bigger crystal that is more expensive than all the other apartment ones.

Intruders from all over the country come and try to steal the crystals from the sky scrapper.

There are a lot of ghosts protecting the crystals from the intruders. The furniture can be used in a way that they will cause some chain reactions.

Water + wind = a longer slide.
Water + Lightning = a lightning chain if multiple enemies are near each other. Zap if only one enemy
...
