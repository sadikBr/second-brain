Name: Make the player's decisions interesting
Created At: 2026-09-10
---
- [ ] Create at least three isotope types with clearly different rules.
- [ ] Start with simple differences: lifespan, size/mass, value, cooling rate, and delivery requirements.
- [ ] Add a visual identity for each type: color, icon, particle effect, and timer treatment.
- [ ] Add one isotope that is valuable but unstable.
- [ ] Add one isotope that is slow/heavy and hard to maneuver.
- [ ] Add one isotope that requires cooling before it can be delivered.
- [ ] Add one meaningful risk interaction: collisions damaging isotopes, chain reactions, heat transfer, blocked delivery, or contamination.
- [ ] Add a combo/efficiency system that rewards skilled sequencing rather than only survival.
- [ ] Add difficulty escalation: shorter spawn intervals, more complex isotope mixtures, faster decay, or changing arena hazards.
- [ ] Ensure difficulty grows predictably enough that failure feels deserved.
- [ ] Create a short tutorial that teaches only: drag, cool, deliver, consequences.
- [ ] Test whether a player can understand all essential rules in under 60 seconds.
