Created At: 2026-09-09

- **Design Objective:** Continuously supply new volatile blocks to the player at regular intervals.
    
- **Steps to Take:**
    
    - [x] Mark a specific entry point on the edge of the arena (e.g., a conveyor belt entrance).
        
    - [x] Set up an automated timer that triggers every few seconds.
        
    - [x] Spawn a new basic block at the entry point whenever the timer finishes.
        
    - [x] Apply a gentle push force to nudge newly spawned blocks into the active floor space.
        
- **Definition of Done:** New blocks automatically enter the room at set time intervals without requiring any player action.
