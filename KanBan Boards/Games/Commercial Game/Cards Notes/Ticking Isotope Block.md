- **Design Objective:** Create a standalone game object that visually counts down its remaining lifespan.
    
- **Steps to Take:**
    
    - [ ] Define the visual appearance of a basic block.
        
    - [ ] Display a clearly readable numerical countdown on top of the block.
        
    - [ ] Make the number count down continuously in real time.
        
    - [ ] Add visual cues (such as color changes or flashing) as the remaining time grows critically low.
        
- **Definition of Done:** A block placed on screen counts down visible seconds, changes visual state as time runs out, and triggers an event when reaching zero.
