---
Name: Tractor-Beam Interaction (Grab & Throw)
Created At: 2026-09-09
---
- **Design Objective:** Give the player direct physical control to grab, drag, and fling blocks using cursor inputs.
    
- **Steps to Take:**
    
    - [x] Select a target block when pressing and holding the primary action button over it.
        
    - [x] Pull and hold the selected block smoothly toward the cursor position as the cursor moves.
        
    - [x] Release the block while moving to transfer momentum, throwing it across the room.
        
- **Definition of Done:** You can pick up any block, drag it around the screen, and fling it across the room with realistic velocity.
