- Create 10–15 minutes of intentional playable content.
- Add 3–5 escalating scenarios or levels, even if they reuse the same arena.
- Create a “daily challenge” style seeded run only if the basic game is already fun.
- Add tutorial, play, pause, settings, results, and credits screens.
- Add keyboard and mouse controls, then controller support.
- Add remappable controls before a public release.
- Add an in-game feedback button or clear instructions for testers.
- Add a debug overlay, disabled in release builds, showing FPS, active isotopes, state, score, and timers.
- Add automated smoke tests for run start/end, isotope delivery, isotope expiry, and restart.
- Test the build on a machine other than your development machine.
- Create export presets early and make regular Windows builds; Godot requires installed export templates and platform setup for release builds. [Godot export guidance](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html)
